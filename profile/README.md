## What it does

War and CWL logs, legend tracking, reminders, rosters, clan stats, auto-roles and data exports, all inside your Discord server. Set it up in Discord or on the [web dashboard](https://app.clashperk.com). The [guide](https://docs.clashperk.com/overview/getting-set-up) covers every command and setting.

| Site | What's there |
| --- | --- |
| [clashperk.com](https://clashperk.com) | What ClashPerk does, and the link to add it |
| [app.clashperk.com](https://app.clashperk.com) | The dashboard for your server's logs, reminders, rosters and roles |
| [docs.clashperk.com](https://docs.clashperk.com) | Setup guide, every command, FAQ |
| [wiki.clashperk.com](https://wiki.clashperk.com) | Stats, costs and upgrade times for every troop, spell, hero and building, straight from the game files |
| [status.clashperk.com](https://status.clashperk.com) | Live status of ClashPerk's services. The Clash of Clans API has its own page at [coc-status.clashperk.com](https://coc-status.clashperk.com) |

## For developers

| Resource | What it is |
| --- | --- |
| [ClashPerk API](https://api.clashperk.com/docs) | OpenAPI reference for the ClashPerk API. Requests need a developer key. Ask in the [Discord server](https://discord.gg/ppuppun) |
| [clashofclans.js](https://github.com/clashperk/clashofclans.js) | Typed JavaScript and TypeScript library for the official Clash of Clans API. On npm as [`clashofclans.js`](https://www.npmjs.com/package/clashofclans.js), docs at [clashofclans.js.org](https://clashofclans.js.org) |
| [Game data](https://assets.clashperk.com/raw.min.json) | Every troop, spell, hero, equipment, pet, building and more, level by level, read from the game files. Also [`units.json`](https://assets.clashperk.com/units.json) (troops, spells, heroes, pets and equipment, with their abilities) and [`translations.json`](https://assets.clashperk.com/translations.json) |
| [Game assets](https://assets.clashperk.com/troops/barbarian/icon.webp) | Icons and artwork from the game, served from `assets.clashperk.com`. Paths are in the game data's `slug` fields |
| Wiki data | Each wiki page's data as JSON: `https://wiki.clashperk.com/data/<category>/<slug>.json`, for example [Barbarian](https://wiki.clashperk.com/data/troops/barbarian.json) |
| [Status API](https://status.clashperk.com/api/summary) | Current health of ClashPerk's services as JSON, open to any site. [`coc-status.clashperk.com/api/summary`](https://coc-status.clashperk.com/api/summary) does the same for the Clash of Clans API |
| `llms.txt` | Plain-text indexes for AI tools: [clashperk.com](https://clashperk.com/llms.txt), [docs](https://docs.clashperk.com/llms.txt), [wiki](https://wiki.clashperk.com/llms.txt) |
